Goal of the language: To make a usable functional programming language with as few types as possible.

1. way to write a lambda
    lb x: {
        return x
    }

    (x:x)
    Supports multi-argument:
    lb x y: {
        return x y
    }

    (x y:(x y))
2. way to apply value to lambda
    (x:x) y

    ((x:x) y)
3. way to assign a value to a variable

    Assignment:
    p := (x:x)
    (p := (x:x))

    Value update:
    p = (x:x)
    (p = (x:x))

    can be used easily:
    p x

4. Two datatypes: Hex/Uint64 and Array
    Array -> [x y z]
        Simple lists. Can act as church lists when used as a function (sort of like a for loop).
        Ex: [1 2 3 4]
            [x y z] F I -> F x (F y (F z I))

    HEX -> '6E
        Hex numbers will be used for pretty much everything, with the compiler automatically translating numbers and other values to hex before adding them to the AST. They can also be used as function that repeats an input the same amount of time as the number value (like church numerals).
        Ex. : 12 -> 'C

    While these two(three?) datatypes aren't strictly required for the programming language to be turing complete and theoretically usable with a perfect cpu and infinite ram, modern cpus aren't designed to run complex pure untyped functional programs, so I decided to add these datatypes as a compromise to allow the programming language to run moderately quickly on modern cpus but still follow the base logic of lambda calculus.
    "hello world" -> ['68 '65 '6C '6C '6F '20 '77 '6F '72 '6C '64]

Explanation of {}:
    Curly-braces allow you to group segments of code together, with a return being optional in case you want the curly brace blocks to return a value. By default it will return nil to the rest of the code. Will be interpretted as a form of closure.
Explanation of ;:
    Semicolons can be used as a newline, but are strictly not required.
    Ex:
    "x = (x:x);x y"
    ==
    "x = (x:x)
    x y"

Language will feature a standard library that translates common programming tokens into their proper lambda calculus functions, like True and False or nil. To allow for low-level programming as that is the eventual goal of the programming language, it will have basic ram management commands (look into ways to do it in a lambda-like way) built-in.

true := (x y:x)
false := (x y:y)
nil := (x:x)

Example programming excerpt (more in test folder):

running := true

print-if-running := lb text times: {
    running {
        times (print text)
        print 4
    } nil
}

print-if-running "hello world" 20

fibonacci:
2back := 0
1back := 1

fibo := lb times: {
    times {
        cur := (add 2back 1back)
        2back = 1back
        1back = cur
        print cur
    } nil
}

fibo 14
